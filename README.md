# Sibigi-AI
My custom Al project 
 ## Description
 Sibigi—AI is a custom AI project designed to provide intelligent responses and assist with various tasks.
 ## Features
 - AI—powered conversational interface.
- Seamless backend integration for AI responses.
 - Easy to deploy on platforms like Render.
 ## Installation
 1. Clone the repository to your local machine.
 2. Install the necessary dependencies using yarn install.
 3. Set up your environment variables, including your Gemini API key.
 ## Usage
 Start the server using node server.js and interact with the AI through the web interface.
